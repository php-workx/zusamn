# /speckit.tasks Workflow

**Purpose**: Generate `specs/[###-feature]/tasks.md` from plan/spec artifacts.

## Required Outputs

- Tasks grouped by user story with priorities.
- Explicit test tasks for every story (unit + integration where relevant).
- Performance validation tasks before release.

## Enforcement

- Reference real paths from plan.md (apps, packages, firebase).
- Align tasks with constitution principles (tests, UX consistency, performance).
