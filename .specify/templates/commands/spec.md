# /speckit.spec Workflow

**Purpose**: Generate `specs/[###-feature]/spec.md` from the user description.

## Required Outputs

- User Stories with priorities and independent tests.
- Functional Requirements and Non-Functional Requirements.
- Measurable Success Criteria and explicit edge cases.

## Enforcement

- Include performance targets in NFRs when the feature is performance-sensitive.
- Require test coverage for each user story.
- UX requirements must reference Tamagui + `@zusamn/ui`.
